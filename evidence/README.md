# Evidence

Run logs, screenshots and demonstration recordings. This is the evidence pack
the weekly reports and evaluation tables should point at.

| Path | Contents |
|---|---|
| [`traces/`](traces/) | Model, retrieval, tool and agent traces (JSONL or similar). Do not hand-edit. |
| [`screenshots/`](screenshots/) | UI or CLI screenshots used in reports |
| [`demo/`](demo/) | Week 8 presentation deck and live-demo recordings |

Keep secrets out of traces. API keys must never appear here.
